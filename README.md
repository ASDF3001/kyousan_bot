# Kyousanshumi（共産趣味ボット）

Discord サーバー「共産趣味」向けの活動実績bot。メッセージ数の集計・ランキング表示・あけおめ最速競争などを行う。

## セットアップ

```bash
pip install -r requirements.txt
cp .env.example .env   # 実トークンを貼る
python3 main.py
```

## 設定と環境変数
詳しくは [settinginfo.md](./settinginfo.md) を参照してください。

## コマンド一覧

| コマンド | 権限 | 説明 |
|----------|------|------|
| `/activity_ranking` | 全員 | ユーザー・スレッドの発言数ランキングを表示。`hide_user=True` でスレッドのみ |
| `/akeome_ranking` | 全員 | 今月のあけおめ最速ランキングを表示 |
| `/omikuji` | 全員 | 今日の運勢（党からの評価）を占う |
| `/stats` | 全員 | 自分の総発言数、**今月の獲得ポイント**、**連続ログイン日数**を表示 |
| `/censor` | 管理者/権限ロール | 指定ユーザーのメッセージを一括削除 |
| `/setting` | 管理者/権限ロール | 走査設定などの管理（詳細は [settinginfo.md](./settinginfo.md)） |
| `/soviet_sync` | 管理者 | 全走査対象のログを手動で再集計 |

## データベース構成（`kyosan_bot.db`）

| テーブル | 内容 |
|----------|------|
| `user_activity` | ユーザーごとの累計発言数 |
| `thread_activity` | スレッドごとの発言数 |
| `akeome_records` | あけおめ計測記録（user_id, date_str, response_ms, is_flying） |
| `scan_targets` | 走査対象チャンネル（channel_id, notify） |
| `bot_config` | 動的設定（race_channel など） |
| `user_points` | **現在のポイント、連続ログイン日数、最終発言状態** |
| `monthly_point_history`| **月別のポイント獲得履歴** |

## 自動タスク & 新機能

- **デイリーログイン & ポイントシステム**
  - **ログインボーナス**: JST 0:00 リセット。その日最初の発言でログイン通知とボーナスポイント（基本10pt + 連続日数×2pt）を獲得します。
  - **発言ボーナス**: メッセージを送信するたびに +1pt 獲得（※全く同じ内容の連投はスパムとみなし無効）。
  - **月間リセット**: 毎月1日 0:00 JST に月間ポイントがリセットされ、履歴に保存されます（連続ログイン日数は維持）。
- **0:00:30 JST** — 前日のあけおめ計測結果を race_channel へ投稿。
- **金曜 20:00 JST** — 週間ランキングを RANKING_CHANNEL へ投稿。
- **4:00 JST（3日に1回）** — 全走査対象チャンネルのログを自動再集計。

## あけおめ最速競争のルール

- 受付チャンネルでスタンプ（指定された `AKEOME_STAMP_ID`）にリアクション。
- **成功**: 当日 0:00:00 〜 0:01:00（JST）。即座に順位リアクションと自己ベストを記録。
- **フライング**: 前日 23:59:00 〜 23:59:59。「シベリア行き」として表示。
- 該当日の 0:00:30 に結果をまとめて投稿。

## 注意

- トークンやIDなどの秘密情報は `.env` にのみ格納。`.env` は `.gitignore` で除外済み。
- SQLite は WAL モード。DBファイル（`*.db*`）はコミット対象外です。
